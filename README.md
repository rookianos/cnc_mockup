# CHRONIC Mockup Studio

靜態 HTML、CSS、JavaScript。解壓縮後，直接用瀏覽器開啟 `index.html` 即可試用。圖稿、實拍底圖與尺寸表在瀏覽器內處理。

## 用 GitHub Pages 發布

1. 建立專用的 GitHub repository。解壓縮 ZIP，將裡面的檔案放在 repository 根目錄，確保根目錄直接看得到 `index.html`、`style.css`、`studio.js` 及 `.nojekyll`。Windows 若隱藏點檔，可直接在 GitHub 根目錄建立空白的 `.nojekyll`。
2. 在 repository 的 **Settings → Pages**，將 **Source** 設為 **Deploy from a branch**。
3. 選擇 **main** 和 **/(root)**，按 **Save**。部署完成後，在同頁開啟 GitHub 提供的網站網址。

公開 repository 的原始碼可供外部查看。透過 GitHub Pages 發布時，請依帳號方案確認站點可見性。
